# Minimundo

**✳️✳️✳️ [Escreva o minimundo do seu projeto aqui...] ✳️✳️✳️**

> ⚠️ **APAGUE ESSA PARTE ANTES DE ENTREGAR SEU TRABALHO**
>
> Apresente o **Minimundo** (também conhecido como Universo de Discurso) do seu projeto. O minimundo é uma descrição textual detalhada, clara e objetiva do cenário do mundo real que o seu sistema ou banco de dados pretende modelar. Ele deve relatar como o negócio funciona, suas regras, restrições, os principais atores envolvidos e os processos diários, servindo como a principal base para a extração de requisitos e para a futura modelagem de dados (como o Diagrama Entidade-Relacionamento).
>
> **Orientações e Referências Bibliográficas**:
>
> - HEUSER, Carlos Alberto. **Projeto de Banco de Dados**. 6. ed. Porto Alegre: Bookman, 2009. _(Referência essencial sobre a definição de requisitos de dados e descrição do minimundo para modelagem)._
> - ELMASRI, Ramez; NAVATHE, Shamkant B. **Sistemas de Banco de Dados**. 7. ed. São Paulo: Pearson, 2018. _(Consulte os capítulos introdutórios sobre o Universo de Discurso e o ciclo de vida do projeto de banco de dados)._
> - [Projeto de Banco de Dados: Modelagem Conceitual (DevMedia)](https://www.devmedia.com.br/modelagem-conceitual-modelo-entidade-relacionamento/27858) - _Artigo detalhando a transição da leitura do minimundo para a modelagem._
> - [Conceitos Básicos de Banco de Dados e Minimundo (Material Aberto - USP)](https://edisciplinas.usp.br/pluginfile.php/4144360/mod_resource/content/1/Aula01-Introducao.pdf)
>
> **Exemplo de Minimundo**
>
> **Tema: Sistema para Biblioteca Universitária**
> "A biblioteca da universidade deseja informatizar seu processo de empréstimos de livros. A biblioteca possui um acervo composto por milhares de livros, sendo que cada livro pertence a uma categoria (ex: Computação, História, Matemática) e pode ter vários exemplares disponíveis. Os usuários da biblioteca são divididos em alunos e professores. Para realizar um empréstimo, o usuário deve estar cadastrado no sistema informando nome, CPF, matrícula e telefone.
>
> Um aluno pode pegar emprestado até 3 exemplares por um prazo de 7 dias, enquanto um professor pode pegar até 5 exemplares por 15 dias. O sistema não pode permitir que um usuário pegue dois exemplares do mesmo livro simultaneamente. Caso ocorra atraso na devolução, o sistema deverá registrar uma multa de R$ 2,00 por dia de atraso. Além disso, o sistema deve emitir relatórios semanais mostrando os livros mais emprestados."
