**✳️✳️✳️

Minimundo: Plataforma de Planejamento Financeiro

A plataforma de planejamento financeiro tem como objetivo simplificar a gestão orçamentária e ajudar os usuários a alcançarem metas. Para utilizar o sistema, o usuário deve se cadastrar informando seu nome, e-mail e senha. Uma vez cadastrado, o usuário pode definir múltiplos objetivos financeiros, especificando para cada um o nome, o valor da meta, o prazo em meses e o valor já acumulado. Para monitorar o andamento da sua vida financeira, o usuário registra seus lançamentos ao longo do tempo. Cada lançamento possui um valor, uma data de ocorrência, uma descrição e é classificado pelo seu tipo (receita ou despesa). Opcionalmente, cada um desses lançamentos deve ser vinculado obrigatoriamente a uma única categoria (ex: Alimentação, Lazer, Transporte), sendo que uma mesma categoria pode agrupar vários lançamentos diferentes. O sistema calcula a conclusão do objetivo de forma automática quando o valor acumulado alcança a meta. Além disso, o sistema utiliza os dados informados para alimentar um simulador de cenários e emitir alertas inteligentes na interface, calculando o impacto de novos gastos no prazo dos objetivos em tempo real, sem armazenar essas simulações como dados permanentes.
